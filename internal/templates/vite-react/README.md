# {{.Name}}

A Vite React Static site, generated by `iidp app create`.

## Developing

```sh
npm install
npm run dev
```

## Building the image

```sh
docker build -t {{.Name}} .
docker run -p 8080:80 {{.Name}}
```

The image builds `dist/` with Vite and serves it with nginx on port 80,
`index.html` at `/`.

## Deploying

There is no deploy workflow in this repository yet: pushing to `main` does
not build or deploy an image until the deploy workflow is added (iidp issue
#12). Until then, the Environment this Application was created with stays
undeployed.
